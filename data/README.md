# data/

`scripts/`가 `../Reference` 자료로 만든 JSON만 둔다 (CLAUDE.md 7). 지금은 모두 빈 자리표시 파일이다.

| 파일 | 내용 | 만드는 스크립트 |
|---|---|---|
| `reservoirs.json` | 저수지 제원 3,402곳 (15044339, 2026-09-07판) | 미작성 |
| `coords.json` | 표준코드별 위경도, 위치 근사 여부 | 미작성 |
| `stations.json` | ASOS 관측소 목록·좌표·자료 기간 | 미작성 (관측소 좌표 출처 확인 필요) |
| `storage-2025.json` | 2025 홍수기 저수율 | 미작성 |
| `rainfall/annual-max/<관측소>.json` | 지속기간별 고정시간 연최대 강우량 | 미작성 |
| `huff/khas-q3.json` | K-HAS Huff 3분위 분포 | 미작성 |
| `validation/kwoni.json` | 권이 설계값 (검증용, CLAUDE.md 6절). 저장소에 포함 | `build_kwoni.py` |
