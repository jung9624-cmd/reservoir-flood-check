# 화면 설계 (wireframe) — 2026-11-19

목적: 검토자가 전국 저수지 중 하나를 찾아 입력값 6가지를 넣고, "이 저수지가 200년 홍수에 안전한가, 왜 그런가"를 30초 안에 읽는다.

- 그림 속 숫자는 모두 실제 값이다.
  - 목록: `data/reservoirs.json`(제원 2026-09-07판)
  - 상세: 권이 4713010226에 보고서 입력값과 설계 내용적표를 넣고 웹앱 기본 설정(포항 1961~2024, actual, 200년, 만수위 시작)으로 `lib/runAll`을 돌린 결과
- 아직 자료가 없는 값은 숫자를 지어내지 않고 "—"와 이유를 적는다.
  - 관측소 거리: `stations.json`이 비어 있음
  - 현재 수위: 수위 API를 아직 연결하지 않음
- 그림은 `design/review.pen`(Pencil)에 있다: 컴포넌트(자동·입력 배지, 적합·부적합), 화면 1·2 데스크톱 1440. 모바일 390은 이번에 그리지 않았고 아래 글 설계만 있다.

## 1. 화면 1 — 전국 목록·지도 (`/`)

### 1.1 데스크톱 1440

```
┌ 머리 ──────────────────────────────────────────────────────────────────────────┐
│ 전국 농업용 저수지 치수안정성 평가     제원 기준일 2026-09-07 · 3,402곳          │
├────────────────────────────────────────────────────────────────────────────────┤
│ [🔍 이름·시군 검색 ................]  본부▾  지사▾  유역면적▾  홍수빈도 100|200|전체 │
│                                       입력 상태 전체|미입력|입력됨|적합|부적합   │
├───────────── 지도 (5단) ─────────────┬──────────── 표 (7단) ─────────────────────┤
│                                      │ 73곳 (경북 · 경주)            정렬: 총저수량▾│

│                                      │ ▶권이  문무대왕면 권이리 640  550  100 [부적합]│
│   지도 위 점을 누르면 표의 그 행이     │                                            │
│   선택되고 표 행을 누르면 지도가 이동  │                          1 2 3 … (50행씩)  │
└──────────────────────────────────────┴────────────────────────────────────────────┘
│ 바닥글                                                                          │
```

- **검색:** 입력하는 동안 바로 거른다. 이름은 893곳이 겹치므로, 검색 결과 행에 소재지를 항상 함께 보인다. 표준코드 10자리를 넣어도 찾는다.
- **필터:** 본부 → 지사는 연결된 선택이다. 지사 목록은 본부를 고르면 좁혀진다.
  - 유역면적 구간: 5 km² 이하 / 5~25.9 / 25.9 이상. 5 km² 이하는 홍수조절 미고려 대상이고, 25.9 이상은 면적감소 경고 대상이다.
  - 홍수빈도: 100년 1,632곳, 200년 1,506곳, 그 밖 264곳.
- **표:**
  - 열은 이름, 소재지(시·군 뒤부터), 유역면적(ha), 총저수량(천m³), 홍수빈도(년), 입력 상태.
  - 숫자 열은 오른쪽 정렬과 tabular figures를 쓴다.
  - 행 높이는 44px, 한 쪽에 50행.
- **입력 상태 칸:** `미입력`은 회색 글자, `입력됨`은 입력 배지이고 판정이 안 나온 경우(빈 칸이 남음)예요. `적합`/`부적합`은 판정 배지로 표시해요. 색이 있는 것은 판정 배지뿐이에요.
- **자료 이상 표시:** 제원 플래그가 있는 행은 이름 뒤에 ⚠를 붙인다(예: 왕신 만수면적 0, 보문 총≠유효+사수).
- **지도:**
  - 점 모양은 위치 출처를 뜻한다. 채운 원은 공유플랫폼 좌표, 빈 원은 소재지 근사 좌표다.
  - 판정은 색으로 칠하고(입력한 곳만), 판정이 없는 곳은 회색이다.
  - 표를 거르면 지도의 점도 같이 걸러진다.
- **제원 기준일:** 화면 위 오른쪽에 늘 보인다.
- 입력 상태는 브라우저에 저장된 입력값에서 나온다(CLAUDE.md 7). 그래서 같은 화면도 사람마다 다르게 보인다.

### ④ 판정 띠

화면 폭 전체를 쓰는 띠 하나. 왼쪽부터 다음 순서로 둔다.

```
[✕ 부적합]  여유고 1.98 m │ 기준 2.00 m (−0.02)   최고수위 EL.167.12   임계 120분   설계홍수량 219.06 m³/s   최대방류량 203.48 m³/s
```

- **판정 칸:** 판정 글자 28px만 색 채움이다. 나머지는 흰 바탕에 먹색이다.
- **여유고:** 여유고와 기준을 같은 크기(32px)로 나란히 쓰고, 그 사이에 세로선을 둔다. 차이(−0.02)는 판정 색 글자로 쓴다.
- **최고수위:** 반올림한 비교값 EL.167.12를 크게 쓴다. 반올림 전 값 167.116은 작은 글씨로 둔다.
- **설계홍수량:** 할증 후(× 1.2) 값이고, `× 1.2 필댐` 작은 글씨를 붙인다.
- **띠 아래 안내 (경고 문장):**
  - "Tc 0.26 hr < 1 hr — 홍수조절 미고려 대상(제5편 8.2.1)"
  - 경계 사례이면: "반올림 전 최고수위로 비교하면 판정이 바뀝니다"

### ⑤ 제당 단면 그림 (주인공)

- **배치:** 데스크톱은 ⑥과 나란히 6단을 쓴다. 높이는 420.
- **그림:** 왼쪽에 저수지 물, 가운데에 사다리꼴 제체를 둔다(필댐). 세로축은 표고(EL.m)이고 154~170을 비례대로 그린다.
- **표고선과 라벨:** 선 오른쪽 끝에 라벨과 값을 쓴다.

| 선 | 표고 | 모양 |
|---|---|---|
| 제정 | EL.169.10 | 먹색 굵은 실선 |
| 최고수위 | EL.167.12 (120분) | 판정 색 굵은 실선 + 물 채움 높이 |
| 허용 최고수위 (제정 − 2.0 m) | EL.167.10 | 먹색 점선 |
| 설계 홍수위 (제원) | EL.167.10 | 회색 가는 실선 |

- **치수선:** 오른쪽에 두 개를 나란히 둔다. 여유고(최고수위 ↔ 제정, 1.98 m)와 기준(허용 최고수위 ↔ 제정, 2.00 m)이다. 두 치수선의 길이 차이가 판정 이유를 보여 준다.
- **라벨이 겹칠 때:** 권이처럼 허용 최고수위와 설계 홍수위가 같은 표고(167.10)이면 라벨 하나로 합쳐 "EL.167.10 허용 최고수위 = 설계 홍수위"로 쓴다.
- **연동:** ⑦에서 행을 누르면 최고수위 선과 물 높이가 그 지속기간 값으로 바뀐다.

### ⑥ 수문곡선

- **패널:** 세 개를 세로로 쌓고 시간축(분)을 함께 쓴다. 0~330분이다.
  1. 강우(mm/10분): 위에서 아래로 내려오는 막대
  2. 유량(m³/s): 유입(× 1.2)은 청색 실선, 방류는 먹색 실선, 첨두마다 값 라벨
  3. 저수위(EL.m): 청색 선, 제정·허용 최고수위·물넘이 마루를 가로 기준선으로 표시
- **최고수위 시각:** 98분에 세 패널을 가로지르는 세로선을 둔다.
- **범례:** 그래프 안 선 끝에 이름을 바로 쓴다. 범례 상자는 두지 않는다.

### 정해야 할 것

- **부적합 색:** "청색 하나"를 지키면서 적합/부적합을 색으로 구분하려면 둘째 색이 하나 필요하다. 그래서 부적합에만 적색을 썼다. 적색을 빼고 먹색 채움으로 할 수도 있다.
- **권이 기본 판정:** 기본 설정(actual, 1961~2024)으로는 **부적합**(여유고 1.98)이고, 보고서와 같은 K-HAS 1961~2022는 적합(2.00)이다. 시연할 때 이 차이를 ⑧에서 설명할지 정해야 한다.
