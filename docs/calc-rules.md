## 2. 확률강우량 (지점빈도)

1. 관측소 시간강우를 시각순으로 놓는다.
   - **기본 = 실제 시각**: 날짜 D의 H01~H23은 D일 01~23시, **H24는 D일 00시 값(전날 23~24시 강우)** [C 3.5].
   - **검증용 옵션 "K-HAS 방식"**: H24를 D일 끝(D+1일 00시)으로 둔다 [C 5.1], [스크립트 `hourly()`].
   - 두 방식은 포항 200년 확률강우량이 최대 2.07 % 다르다(data-audit 5.1). 보고서 값과 비교할 때만 K-HAS 방식을 쓴다.
2. 빈칸은 0으로 채우고 빈칸 수를 센다 [스크립트]. 빈칸이 무강우인지 결측인지는 **확인 필요**(2018년까지 빈칸, 2019년부터 0).
3. 지속기간 D = 1, 2, 3, 4, 6, 9, 12, 15, 18, 24시간의 이동합(rolling sum)을 구하고 해마다 최댓값을 뽑는다.
   - 연도는 **구간 끝 시각에서 1시간을 뺀 시각의 연도**다(1월 1일 00시에 끝나는 구간은 전년도) [스크립트 `annual_max()`].
4. 고정시간 → 임의시간 환산: Y = 0.1346·X^−1.417 + 1.0014 (X = 지속기간, 시간). 연최대 × Y [C 5.1], [보고서 표 3.10].
5. Gumbel 확률가중모멘트법, 오름차순 x(1) ≤ … ≤ x(n) [C 5.1], [스크립트 `gumbel_pwm()`]:
   - b0 = 평균
   - b1 = Σ (i−1)/(n−1) · x(i) / n (i = 1…n)
   - α = (2b1 − b0)/ln 2
   - ξ = b0 − 0.5772 α
   - x_T = ξ − α · ln(−ln(1 − 1/T)), T = 200
6. 관측소 조건: 30년 이상 [C 5.1]. 이 조건을 "자료가 있는 해의 수"로 셀지 "첫해~마지막 해"로 셀지는 **확인 필요**(92곳 중 각각 70곳 / 69곳).
7. 면적우량: 유역 ≥ 25.9 km²(2,590 ha)이면 면적감소계수 대상. 1차판은 경고만 한다 [C 5-2]. 전국 78곳.
8. 지역빈도는 쓰지 않는다(향후과제) [C 5.1].

검증: 포항(138), 1961~2022, K-HAS 방식 → 보고서 200년 값과 0.3 % 이내 [C 6.4]. 재현 결과 최대 차이 −0.281 %(120분) (data-audit 5.1).

## 4. Clark 단위도

- 시간-면적 곡선 (T = t/Tc) [C 5.2]:
  - At/A = 1.414·T^1.5 (0 ≤ T ≤ 0.5)
  - At/A = 1 − 1.414·(1 − T)^1.5 (0.5 < T < 1), T ≥ 1이면 1
- 구간 면적비: dA_k = TA((k+1)Δt/Tc) − TA(kΔt/Tc). **Tc를 Δt 배수로 반올림하지 않는다** [C 5.2].
- 선형저수지: CA = Δt / (K + 0.5Δt), O_i = CA·I_i + (1 − CA)·O_(i−1). Δt와 K는 같은 단위(분)로 맞춘다 [C 5.2].
  - 선형저수지 점화식의 구체적 형태(I_i 하나인지, (I_i + I_(i−1))/2인지)는 CLAUDE.md에 CA만 있다 → **확인 필요**.
- 유량 환산: Q [m³/s] = 유효우량 [mm] × 면적 [km²] / (0.06 × Δt [분]) [C 5-12].
- Tc·K를 유로연장·최원점 표고로 구할 때: 서경대 공식 Tc = 0.214·L·H^−0.144, K = α·(A/L²)^0.02·Tc, α = 1.45 / 1.20 / 1.70 [C 5-6].
  - H의 정의(최원점 표고 자체인지, 출구와의 표고차인지)와 단위, α 세 값 중 어느 것을 어떤 조건에서 쓰는지는 **확인 필요**.
  - 권이 보고서는 서경대 공식이 아니라 **연속형 Kraven 공식**으로 Tc를 정했다(15.5분, 보고서 표 3.1). 권이 검증은 Tc 0.26 hr, K 0.20 hr를 직접 입력한다 [C 6.1].
- 기저유량: 보고서 3.3.1은 "직접 유출수문곡선을 계산한 후 기저유량을 더하여"라고 쓰지만 CLAUDE.md에는 기저유량이 없다 → **확인 필요**.

## 5. 내용적 곡선과 수정 Puls 홍수추적

### 5.1 내용적 곡선

- 공공데이터 곡선: S(h) = S만수·((h − h사수)/(h만수 − h사수))^m, m = A만수·(h만수 − h사수)/S만수 [C 5.3].
  - 단위 변환: S만수 = 총저수량 [천m³] × 1,000 → m³, A만수 = 만수면적 [ha] × 10,000 → m².
  - 만수위 위로는 이 식을 연장해 쓴다(외삽). 권이에서 설계표와 168.5 m에서 −0.4 % 차이.
  - m ≤ 0이거나 매우 큰 저수지가 있다(data-audit 2.2). 처리 방법 **확인 필요**.
- 설계 내용적표를 입력하면 그것을 우선한다 [C 5.3]. 표 사이 보간 방법(선형 등)은 **확인 필요**(보고서 3.4.1: 표고별 저류량은 평균단면적법으로 산정).

### 5.2 방류량

- O(h) = Σ C·L·max(0, h − 마루)^1.5, C 기본 2.0 [C 5-9]. 물넘이와 추가 방류시설(열림일 때)을 더한다.
- 보고서 3.4.1은 오리피스 식 O = C·A·√(2gH)도 제시한다. 수문(전도식 4.0 × 1.5 m)을 웨어 식으로 다루는 것은 CLAUDE.md 결정이다. 수문이 언제 오리피스 흐름이 되는지는 **확인 필요**.

### 5.3 추적

- 저류방정식: (I_i + I_(i+1))/2 · Δt − (O_i + O_(i+1))/2 · Δt = S_(i+1) − S_i [보고서 3.4.1].
- 정리: (I_i + I_(i+1))/2 · Δt + S_i − O_i·Δt/2 = S_(i+1) + O_(i+1)·Δt/2. 오른쪽을 h_(i+1)의 함수로 보고 **이분법**으로 푼다 [C 5-9].
- 추적 Δt = 1분, 유입량은 10분 수문곡선을 **1분으로 보간**한다 [C 5-9, 5-12]. 보간 방법(선형)은 **확인 필요**.
- 초기 수위 = 만수위 [보고서 3.4.3 "저수지 초기수위는 만수위"]. CLAUDE.md에는 명시 없음.
- 이분법 수렴 기준, 탐색 구간, 추적 종료 시각은 **확인 필요**.
