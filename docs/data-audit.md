### 2.2 내용적 곡선 지수 m (CLAUDE.md 5.3 식을 제원에 적용)

m = 만수면적[ha]×10⁴ × (만수위 − 사수위) / (총저수량[천m³]×10³)

| m 범위 | 개수 (2026판) |
|---|---|
| m ≤ 0 | 10 |
| 0 < m < 0.5 | 34 |
| 0.5 ≤ m < 1 | 189 |
| 1 ≤ m ≤ 3 | 2,812 |
| 3 < m ≤ 5 | 202 |
| m > 5 | 155 (그중 m > 10: 74) |

- 중앙값 1.76, 최소 −557.09, 최대 2,288.01. m ≤ 0이나 m이 매우 큰 곳은 위 2.1의 이상값(만수위 ≤ 사수위, 만수면적 0 등)에서 나온다.
- 이런 저수지에서 공공데이터 곡선을 쓸 수 있는지, 쓸 수 없으면 화면에서 어떻게 할지는 **확인 필요**.
- 권이: m = 9.9×10⁴ × 11.9 / 550,000 = **2.142**. 설계 내용적표와 비교하면 EL.165.9 −0.0 %, 167.1 +0.1 %, 168.5 −0.4 %, 160.0 −10.4 %.

### 9.1 입력 검사가 돌려준 이유 (저수지 수, 한 곳에 이유가 여러 개일 수 있음)

| 항목 | 이유 | 저수지 수 | 원인 |
|---|---|---|---|
| 제정표고 | 만수위보다 높아야 함 | 7 | 2.1의 홍수위 < 만수위(15곳) 중 홍수위 + 2 m가 만수위 이하인 곳 |
| 제원.만수면적 | 없거나 0 (내용적 곡선 불가) | 6 | 2.1의 만수면적 = 0 (단산, 신항, 소암, 백석, 만학, 왕신) |
